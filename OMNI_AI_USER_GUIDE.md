## 1. Welcome to OMNI AI

**OMNI AI** is the unified intelligence command center of the OMNI Cognitive Operating System. Rather than forcing you to jump between separate chatbot subscriptions, slide generators, research tools, and spreadsheet assistants, OMNI AI brings all models, enterprise knowledge, creative tools, and autonomous agents together into **one cohesive, sovereign workspace**.

---

## 2. Navigating the 16 Functional Hubs

OMNI AI is organized into 16 purpose-built hubs accessible via the top navigation bar or the universal `Cmd+K` Command Bar:

```
[Home] [Chat] [Search] [Research] [Knowledge] [Create] [Code] [Agents]
[Team AI] [Workflows] [Consensus] [Arena] [Workspace] [Marketplace] [Plans] [White-Label]
```

### 2.1 Home Hub
* **Unified Intelligence Overview:** View real-time system status, compute quota utilization, active BYOK providers, and recent generation history.
* **Universal Prompt Composer:** Type natural language prompts, attach files, select output modalities, or select target routing profiles.
* **Quick Launch Shortcuts:** Jump instantly into Deep Research dossiers, slide deck generation, or code execution.

### 2.2 Chat Hub
* **Multi-Model Conversations:** Chat seamlessly with Google Gemini 1.5/2.0, Anthropic Claude 3.5 Sonnet, OpenAI GPT-4o, and private local models.
* **Parameter Controls:** Adjust temperature, top-p, maximum token output, and custom system instructions.
* **Conversation Management:** Pin important dialogues, search historical transcripts, or export conversations as Markdown, PDF, or JSON.

### 2.3 Grounded Search Hub
* **Real-Time Web Intelligence:** Perform grounded queries backed by multi-engine web indexes.
* **Verified Citations:** Every factual assertion includes interactive clickable citation pills with domain reliability ratings.
* **Source Drawer:** Expand the right-hand drawer to read original snippets, publication timestamps, and cached source pages.

### 2.4 Deep Research Hub
* **Autonomous Multi-Stage Investigation:** Input complex research topics (e.g., *"Comparative study of quantum computing cryptography standards for fintech"*).
* **Transparent Execution Pipeline:** Watch OMNI decompose the question into sub-queries, harvest sources across global data nodes, cross-validate findings, and compile a multi-page dossier.
* **Exportable Intelligence Dossiers:** Download structured reports formatted with executive summaries, methodology sections, and bibliography references.

### 2.5 Knowledge Hub (Enterprise RAG)
* **Knowledge Spaces:** Create isolated document vaults for teams, departments, or private projects.
* **Multi-Format Ingestion:** Upload PDFs, Word documents, CSVs, code files, and web URLs.
* **Chunk Inspector & Vector Telemetry:** View how documents are tokenized, embedded, and retrieved during hybrid search queries.
* **Access Control:** Grant or revoke document access per user role with instantaneous ACL enforcement.

### 2.6 Create Studio
* **Document Studio:** Generate rich, formatted executive briefings, technical specifications, and marketing copy with block-based editing.
* **Presentation Deck Builder:** Create pitch decks and executive slide decks with automated layout theming, high-contrast typography, and SVG graphics.
* **Financial Sheet Studio:** Build multi-tab financial spreadsheets with deterministic formula calculations, automated data cleaning, and KPI charts.

### 2.7 Code Studio
* **Containerized Polyglot Sandbox:** Write and execute code in TypeScript, Python, and SQL.
* **Security Isolation:** Code runs within an isolated WebAssembly/MicroVM sandbox with zero access to your local computer or host network.
* **Code Explanations & Refactoring:** Ask OMNI to optimize algorithms, generate unit tests, or detect security vulnerabilities.

### 2.8 Autonomous Agents Hub
* **Agent Swarm Directory:** Deploy specialized agents equipped with specific tool bundles and memory scopes.
* **Autonomy Levels (L0–L5):** Configure how autonomously an agent can act (from manual confirmation on every step to fully autonomous execution).
* **Human-in-the-Loop Co-Signing:** High-risk actions (e.g., creating real invoices, modifying production databases) trigger a secure approval modal.

### 2.9 Team AI & Departmental Hub
* **Hierarchical Workspaces:** Departmental divisions (Engineering, Product, Legal, Finance, Marketing) with dedicated agents and knowledge bases.
* **Resource Delegation:** Assign custom prompts and tools to specific teams while preventing cross-department data exposure.

### 2.10 Workflows & Synthesis Hub
* **Cross-Application Automation:** Create visual multi-step pipelines connecting OMNI Chat, Knowledge Spaces, Code Interpreter, and external webhooks.
* **Conditional Branching:** Set logic gates based on sentiment, confidence scores, or numerical thresholds.

### 2.11 Consensus Hub
* **Multi-Model Synthesis:** Query multiple foundation models simultaneously (e.g., Gemini + Claude + GPT-4o).
* **Agreement Scoring:** OMNI evaluates the divergence and consensus across all answers, synthesizing a single unified, high-confidence conclusion.

### 2.12 Battle Arena Hub
* **Blind Model Benchmarking:** Test two anonymous models on the same prompt side-by-side.
* **Elo Leaderboard:** Vote on the superior completion to contribute to the decentralized model quality rankings.

### 2.13 Workspace Hub
* **Prompt Registry:** Access shared team prompt templates with version history and usage tracking.
* **Compliance Audit Logs:** Review every AI query, token count, cost deduction, and user session log for compliance.

### 2.14 AI Marketplace
* **Community & Enterprise Agents:** Discover, test, and install third-party agents, prompt packs, and knowledge connectors.
* **Creator Monetization:** Publish your custom agents and receive an 80% revenue split paid in OMNI Credit Units (OCU).

### 2.15 Plans & Credits Hub
* **Tier Management:** Switch between Free, Pro, Team, and Enterprise sovereign subscriptions.
* **OCU Credit Wallet:** View real-time balance, purchase top-up bundles, or enable automated balance reloads.

### 2.16 White-Label & Partner Hub
* **Custom Enterprise Branding:** Configure custom logos, brand colors, custom subdomains, and localized legal disclaimers.
* **Partner Reseller Network:** Manage sub-tenants, monitor gross margins, and track affiliate commission payouts.

## 3. Keyboard Shortcuts & Tips

* `Cmd + K` (Mac) / `Ctrl + K` (Windows): Open Universal AI Command Bar.
* `Esc`: Close drawers, modals, or active command bars.
* `Shift + Enter`: Insert new line in prompt composers without sending.
* `Cmd + Enter`: Immediately dispatch prompt to active model.
